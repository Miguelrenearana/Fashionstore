# CU-01 — Iniciar sesión

> Paquete: **Autenticación y gestión de usuarios**

| CASO DE USO | PROPÓSITO | ACTORES | ACTOR INICIADOR |
| --- | --- | --- | --- |
| CU-01 | Permitir que los usuarios accedan a FASHIONSTORE | Usuario (Administrador, Empleado o Cliente) | Usuario |

| PRECONDICIÓN | FLUJO DE SUCESO PRINCIPAL | POSTCONDICIÓN | EXCEPCIÓN |
| --- | --- | --- | --- |
| El usuario posee una cuenta activa con contraseña válida. | 1. El usuario envía sus credenciales (email y contraseña). 2. El sistema autentica (`POST /auth/login`) y emite un token JWT con los roles. 3. La UI carga el perfil y roles (`GET /users/me`). 4. Se muestra el panel correspondiente a su rol. | El usuario queda con sesión activa (JWT) y acceso según rol. | Credenciales inválidas → 401. Cuenta inactiva → 401. Email o contraseña vacíos → 422. |
