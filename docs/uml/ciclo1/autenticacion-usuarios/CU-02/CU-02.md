# CU-02 — Cerrar sesión

> Paquete: **Autenticación y gestión de usuarios**

| CASO DE USO | PROPÓSITO | ACTORES | ACTOR INICIADOR |
| --- | --- | --- | --- |
| CU-02 | Permitir que un usuario finalice de forma segura su sesión en la plataforma | Usuario autenticado | Usuario |

| PRECONDICIÓN | FLUJO DE SUCESO PRINCIPAL | POSTCONDICIÓN | EXCEPCIÓN |
| --- | --- | --- | --- |
| El usuario tiene una sesión activa (token JWT). | 1. El usuario presiona "Cerrar sesión". 2. La UI llama `POST /auth/logout` (JWT sin estado). 3. El servidor confirma con `Message`. 4. La UI elimina el token del almacenamiento local. 5. Se redirige al usuario a `/login`. | La sesión se cierra de forma segura: el token queda descartado en el cliente y no puede reutilizarse desde esa UI. | Sesión ya cerrada: sin impacto (el token deja de existir localmente). Fallo de red → se limpia igualmente el token local. |
