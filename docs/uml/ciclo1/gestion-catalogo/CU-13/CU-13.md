# CU-13 — Buscar y filtrar prendas

> Paquete: **Gestión y consulta del catálogo**

| CASO DE USO | PROPÓSITO | ACTORES | ACTOR INICIADOR |
| --- | --- | --- | --- |
| CU-13 | Permitir al cliente localizar prendas de acuerdo con características determinadas del catálogo | Cliente | Cliente |

| PRECONDICIÓN | FLUJO DE SUCESO PRINCIPAL | POSTCONDICIÓN | EXCEPCIÓN |
| --- | --- | --- | --- |
| Existen prendas en el catálogo. No requiere autenticación. | 1. El cliente ingresa texto libre y/o selecciona filtros (categoría, sucursal). 2. El sistema consulta `GET /catalog?search=&category_id=&branch_id=&page=&size=`. 3. El cliente carga las categorías para el filtro (`GET /catalog/categories`). 4. El sistema devuelve únicamente las prendas que cumplen los criterios. | El cliente ve un listado filtrado y paginado de prendas. | Sin resultados → lista vacía (200). Parámetros inválidos → 422. |
