# CU-11 — Gestionar promociones

> Paquete: **Gestión y consulta del catálogo**

| CASO DE USO | PROPÓSITO | ACTORES | ACTOR INICIADOR |
| --- | --- | --- | --- |
| CU-11 | Permitir al administrador crear, listar, actualizar y eliminar promociones (descuentos por porcentaje con vigencia temporal) asociadas a prendas del catálogo. | Administrador | Administrador |

| PRECONDICIÓN | FLUJO DE SUCESO PRINCIPAL | POSTCONDICIÓN | EXCEPCIÓN |
| --- | --- | --- | --- |
| El administrador está autenticado. Existen prendas activas en el catálogo. | 1. El administrador accede a la gestión de promociones. 2. El sistema lista las promociones existentes con paginación y filtros. 3. El administrador crea una nueva promoción indicando nombre, descripción, porcentaje de descuento, fechas de vigencia y seleccionando las prendas asociadas. 4. El sistema valida que la fecha de inicio sea anterior a la de fin y que las prendas existan y estén activas. 5. El sistema crea la promoción con sus asociaciones a prendas. 6. El administrador puede listar, actualizar o eliminar (soft delete) promociones. | La promoción queda registrada y disponible para aplicarse en el catálogo y checkout según su vigencia. | Fechas inválidas (inicio ≥ fin) → 422. Prendas no encontradas/inactivas → 422. Promoción no encontrada → 404. |

## Endpoints

| Método | Ruta | Descripción |
| --- | --- | --- |
| POST | `/api/v1/promotions` | Crear promoción |
| GET | `/api/v1/promotions` | Listar promociones (paginado, filtros) |
| GET | `/api/v1/promotions/active` | Promociones vigentes |
| GET | `/api/v1/promotions/{id}` | Detalle de promoción |
| PATCH | `/api/v1/promotions/{id}` | Actualizar promoción |
| DELETE | `/api/v1/promotions/{id}` | Eliminar (soft delete) |
| GET | `/api/v1/promotions/by-garment/{garment_id}` | Promociones activas de una prenda |

## Validaciones

- `start_at` < `end_at` (fecha inicio anterior a fin)
- `discount_percent` entre 0 y 100
- Al menos una prenda asociada (`garment_ids` no vacío)
- Prendas deben existir y estar activas (`is_active = true`)
- Fechas con zona horaria UTC

## Modelo de Datos

- **Promotion**: id, name, description, discount_percent, start_at, end_at, status, created_at, updated_at
- **PromotionGarment**: id, promotion_id, garment_id (relación N:M)
