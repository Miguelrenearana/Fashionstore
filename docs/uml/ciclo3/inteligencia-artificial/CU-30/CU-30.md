# CU-30 — Recomendar productos mediante IA

> Paquete: **Inteligencia artificial**

| CASO DE USO | PROPÓSITO | ACTORES | ACTOR INICIADOR |
| --- | --- | --- | --- |
| CU-30 | Recomendar productos mediante IA usando similitud semántica (embeddings) e historial de navegación | Cliente | Cliente |

| PRECONDICIÓN | FLUJO DE SUCESO PRINCIPAL | POSTCONDICIÓN | EXCEPCIÓN |
| --- | --- | --- | --- |
| El cliente está autenticado. Existen productos con embeddings generados. | 1. El cliente accede a "Recomendaciones para ti" o a un producto. 2. El sistema consulta el historial de navegación o el producto actual. 3. Se genera embedding del producto/historial. 4. Se busca en VectorStore (pgvector) los productos más similares. 5. Se filtran productos ya vistos/comprados. 6. Se devuelve lista paginada con score de similitud. | El cliente visualiza recomendaciones personalizadas con score de similitud. | Producto no encontrado → 404. Sin embeddings → lista vacía. Sin historial → productos tendencia. |

## Endpoints

| Método | Ruta | Descripción |
| --- | --- | --- |
| GET | `/api/v1/ai/recommendations` | Recomendaciones (source=similarity|history|trending) |
| GET | `/api/v1/ai/recommendations/trending` | Productos tendencia |
| GET | `/api/v1/ai/recommendations/by-variant/{variant_id}` | Similares a un producto |
| POST | `/api/v1/ai/view/{variant_id}` | Registrar vista para historial |

## Respuesta (RecommendationResponse)

```json
{
  "items": [
    {
      "variant_id": 5,
      "garment_name": "Camisa Slim Fit",
      "variant_sku": "CSF-M-BLU",
      "size_name": "M",
      "color_name": "Azul",
      "price": 120.00,
      "score": 0.87
    }
  ],
  "source": "similarity"
}
```

## Validaciones

- `limit`: 1-50
- `source`: similarity | history | trending
- `source_variant_id`: obligatorio si source=similarity

## Implementación

- **Embeddings**: `sentence-transformers` (all-MiniLM-L6-v2) + `pgvector` (cosine similarity)
- **VectorStore**: `app/ml/vector_store.py` (pgvector cosine similarity + IVFFlat index)
- **RecommenderService**: `app/ml/recommender.py` (content-based + collaborative)
- **VectorStore**: `app/ml/vector_store.py` (pgvector cosine similarity + IVFFlat index)
