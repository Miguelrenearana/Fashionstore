# CU-31 — Asistir al cliente mediante IA

> Paquete: **Inteligencia artificial**

| CASO DE USO | PROPÓSITO | ACTORES | ACTOR INICIADOR |
| --- | --- | --- | --- |
| CU-31 | Asistir al cliente mediante chat con IA (Ollama local) para consultas de productos, tallas, disponibilidad, pedidos y FAQs. | Cliente | Cliente |

| PRECONDICIÓN | FLUJO DE SUCESO PRINCIPAL | POSTCONDICIÓN | EXCEPCIÓN |
| --- | --- | --- | --- |
| El cliente está autenticado. Ollama corriendo localmente con modelo cargado. | 1. El cliente abre el chat en la web/app. 2. Escribe su consulta (ej. "¿Tienen esta camisa en talla M?"). 3. El sistema construye prompt con contexto (catálogo, FAQ, historial). 4. Se envía a Ollama (modelo local: llama3.2/codellama). 4. Se devuelve respuesta en streaming o bloque. 5. El cliente puede seguir preguntando (historial de conversación). | El cliente recibe respuesta contextualizada y puede continuar la conversación. | Ollama no disponible → fallback a respuestas predefinidas. Error de modelo → mensaje de error amigable. |

## Endpoints

| Método | Ruta | Descripción |
| --- | --- | --- |
| POST | `/api/v1/ai/chat` | Chat con asistente IA (contexto + historial) |

## Request (AIChatRequest)

```json
{
  "message": "¿Tienen esta camisa en talla M color azul?",
  "context": "catálogo",
  "history": [
    {"role": "user", "content": "Busco camisas"},
    {"role": "assistant", "content": "Tenemos varias opciones..."}
  ],
  "temperature": 0.7,
  "max_tokens": 500
}
```

## Response (AIChatResponse)

```json
{
  "message": "Sí, tenemos esa camisa en talla M color azul. Quedan 5 unidades en la sucursal Centro.",
  "model": "llama3.2",
  "tokens_used": 42
}
```

## Configuración Ollama

```bash
# Instalar Ollama
curl -fsSL https://ollama.com/install.sh | sh

# Descargar modelos
ollama pull llama3.2
ollama pull codellama
```

## Configuración (.env)

```bash
OLLAMA_BASE_URL=http://localhost:11434
OLLAMA_MODEL=llama3.2
OLLAMA_SQL_MODEL=codellama
```

## Implementación

- **Ollama Client**: `app/services/ai_service.py` → `chat()`, `chat_with_context()`
- **Modelos**: `llama3.2` (general), `codellama` (SQL)
- **Contexto**: Catálogo (RAG), FAQs, historial de conversación
- **RAG**: Embeddings de productos + pgvector para recuperación semántica
