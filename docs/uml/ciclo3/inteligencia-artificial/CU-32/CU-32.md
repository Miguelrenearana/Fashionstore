# CU-32 — Generar consultas y reportes mediante IA

> Paquete: **Inteligencia artificial**

| CASO DE USO | PROPÓSITO | ACTORES | ACTOR INICIADOR |
| --- | --- | --- | --- |
| CU-32 | Permitir al administrador generar reportes SQL desde lenguaje natural, ejecutarlos de forma segura y obtener resultados tabulares. | Administrador | Administrador |

| PRECONDICIÓN | FLUJO DE SUCESO PRINCIPAL | POSTCONDICIÓN | EXCEPCIÓN |
| --- | --- | --- | --- |
| El administrador está autenticado con rol ADMIN. Ollama corriendo con modelo `codellama`. | 1. El administrador accede a "Reportes IA". 2. Escribe prompt en lenguaje natural (ej. "Ventas del último mes por sucursal"). 3. El sistema genera SQL seguro usando `codellama`. 4. Se valida el SQL (solo SELECT, tablas permitidas, LIMIT). 5. Se ejecuta la consulta en PostgreSQL. 6. Se devuelve resultado tabular + SQL generado (opcional). | El administrador obtiene resultado tabular y opcionalmente el SQL generado. | SQL inválido → 400. Tablas no permitidas → 400. Timeout → 504. |

## Endpoints

| Método | Ruta | Descripción |
| --- | --- | --- |
| POST | `/api/v1/ai/reports/generate` | Generar y ejecutar reporte IA |
| POST | `/api/v1/ai/reports/explain` | Generar y explicar SQL sin ejecutar |

## Request (AIReportRequest)

```json
{
  "prompt": "Ventas del último mes por sucursal con total y cantidad",
  "max_rows": 100,
  "explain": true
}
```

## Response (AIReportResponse)

```json
{
  "columns": ["sucursal", "total_ventas", "cantidad"],
  "rows": [
    ["Sucursal Centro", 15000.00, 45],
    ["Sucursal Norte", 8500.00, 28]
  ],
  "row_count": 2,
  "generated_sql": "SELECT s.name as sucursal, SUM(vd.unit_price * vd.quantity) as total_ventas, COUNT(*) as cantidad FROM venta v JOIN sucursal s ON v.branch_id = s.id JOIN venta_detalle vd ON v.id = vd.sale_id WHERE v.paid_at >= NOW() - INTERVAL '1 month' GROUP BY s.id ORDER BY total_ventas DESC LIMIT 100",
  "execution_time_ms": 45.2
}
```

## Reglas de seguridad (SQL Validation)

1. **Solo SELECT** — No DROP, DELETE, UPDATE, INSERT, ALTER, CREATE, TRUNCATE
2. **Tablas permitidas** (whitelist): `venta`, `venta_detalle`, `pago`, `reserva`, `reserva_detalle`, `inventario`, `movimiento_inventario`, `recepcion_producto`, `recepcion_producto_detalle`, `prenda`, `prenda_variante`, `categoria`, `talla`, `color`, `temporada`, `coleccion`, `cliente`, `usuario`, `sucursal`, `proveedor`, `promocion`, `promocion_prenda`, `recepcion_producto`, `recepcion_producto_detalle`, `inventario`, `movimiento_inventario`, `bitacora_sistema`, `notificacion`, `recomendacion`, `historial_navegacion`
3. **Solo SELECT** — No DML/DDL
3. **LIMIT obligatorio** (máx. 1000 filas)
4. **Solo alias** para columnas
4. **Timeout** 5s en ejecución

## Ejemplos de prompts

| Prompt | SQL Generado |
| --- | --- |
| "Ventas del último mes por sucursal" | `SELECT s.name, SUM(vd.unit_price * vd.quantity) FROM venta v JOIN sucursal s ON v.branch_id = s.id JOIN venta_detalle vd ON v.id = vd.sale_id WHERE v.paid_at >= NOW() - INTERVAL '1 month' GROUP BY s.id ORDER BY total DESC LIMIT 100` |
| "Productos más vendidos" | `SELECT pv.name, SUM(vd.quantity) as total FROM venta_detalle vd JOIN prenda_variante pv ON vd.variant_id = pv.id JOIN prenda p ON pv.garment_id = p.id GROUP BY pv.id ORDER BY total DESC LIMIT 10` |
| "Stock bajo por sucursal" | `SELECT s.name, pv.name, i.quantity FROM inventario i JOIN sucursal s ON i.branch_id = s.id JOIN prenda_variante pv ON i.variant_id = pv.id WHERE i.available < 5 ORDER BY i.quantity ASC LIMIT 50` |
