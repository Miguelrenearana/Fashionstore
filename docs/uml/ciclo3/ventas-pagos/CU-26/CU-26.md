## Endpoints

| Método | Ruta | Descripción |
| --- | --- | --- |
| GET | `/api/v1/receipts` | Listar comprobantes del cliente (paginado, filtro sale_id) |
| GET | `/api/v1/receipts/{receipt_id}` | Detalle completo de comprobante |

## Validaciones

- Solo el cliente propietario ve sus comprobantes (filtro por `client_id` vinculado al `user_id`)
- Admin/Manager/Cajero pueden ver comprobantes de cualquier venta (vía `sale_id` filter)
- Respuesta incluye: tipo (invoice/credit_note), RNC/CUF, total, estado venta, sucursal, items con variant/garment/size/color/cantidad/precio

## Modelo de Datos

- **Receipt**: id, sale_id, type (invoice/credit_note), rnc_or_cuf, document_url, created_at
- **Sale**: id, client_id, branch_id, total_amount, status, paid_at, invoice_number
- **SaleDetail**: variant_id, quantity, unit_price
- **GarmentVariant**: garment, size, color

## Notas

- Cliente autenticado → `Client` vinculado a `User` → filtra `Receipt.sale.client_id = client.id`
- Admin/Manager → sin filtro de cliente, puede usar `sale_id` query param
- Detalle hace joins: Receipt → Sale → Branch + SaleDetail → GarmentVariant → Garment + Size + Color
